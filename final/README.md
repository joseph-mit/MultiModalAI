# Adversarial Modality Interactions

Code for *Adversarial Modality Interactions: Provenance-Aware Partial Information Decomposition for Strategically-Generated Multimodal Content in Real Estate.*

The paper extends standard partial information decomposition along the provenance axis: when one modality is strategically generated by an agent with a stake in the outcome, its unique information further decomposes into truthful and adversarial parts. We apply this to 20,254 Boston-area real-estate listings with text, photos, Street View, and satellite tiles.

## Files

- `experiments.py` runs every analysis in the paper end to end. Reads two input files, writes results as `.npz` and a `summary.json` to the working directory.
- `figures.py` produces the 30 paper figures from the `.npz` files. Run after `experiments.py`.
- `data_pipeline/` contains the scripts that build the two input files from raw Zillow, Google Street View, satellite, and census sources. See its README for the collection and cleaning steps.

## Running

```
python experiments.py
python figures.py
```

The two input files should sit next to the scripts:

- `boston_listings_with_census_newest.csv` (23,624 rows, 42 columns)
- `clip_embeddings_reupload.npz` (four CLIP modality embeddings plus availability masks)

To regenerate these from scratch, see `data_pipeline/README.md`.

## What gets written

`experiments.py` writes one `.npz` per analysis (`results_headline.npz`, `results_causal.pkl`, `results_synergy.npz`, etc.) plus a single `summary.json` with the headline scalars in plain text. The output filenames are stable, so you can rerun a single analysis and overwrite just that one file.

`figures.py` writes `figure_1_pipeline.png` through `figure_30_spatial.png`. Each function loads its own `.npz` and is independent of the others, so a missing input just skips that figure rather than breaking the script.

## Notes

The Gaussian-MI estimator is used throughout for speed and to admit an analytic bootstrap. Appendix F validates against KSG kNN MI. Permutation nulls use 1000 reps for the headline atom, 200 for the synergy atom. Cluster bootstrap is 500 reps at the building level.

The within-property and within-building fixed effects use cluster-robust standard errors. The broker-LOO instrument requires brokers with at least 5 listings.

Five-seed reproducibility runs at standard deviation 1e-5 because the Ridge solution is essentially deterministic given the regularization; the only fold-level variation comes from the K-fold split.
