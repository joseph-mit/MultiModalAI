# Midterm README
Multimodal fusion treats all inputs as honest observations of reality, but in many domains some modalities are generated by agents with incentives to mislead. We show that zero-shot prompted scoring and supervised scoring measure fundamentally different constructs: supervised models learn what something is worth, while prompts capture how hard an agent tries to make it look good. Their divergence detects strategic intent, and no price-based supervised objective can recover the signal because the training target reflects value, not effort. We validate this insight in real estate, where listing text and photographs are curated by a seller’s agent while Street View imagery, satellite photos, and public records are not. Our method, quality-calibrated alignment, scores each modality on a quality axis via CLIP zero-shot classification and compares the strategic average to the objective average, requiring no labeled data or fine-tuning. On 6,893 sold properties across seven Boston-area municipalities, misaligned listings are half as likely to sell above asking (logistic odds ratio 0.495 for selling above list price, p= 0.0003). A mixture-of-experts model trained only to predict sale price independently learns to discount strategic modalities for misaligned properties: zeroing out strategic inputs shifts log-price predictions by +0.093 for misaligned listings (roughly +10% in price; removing the misleading signal helps) but by−0.073 for aligned ones (roughly−7%; removing truthful signal hurts), with p<0.0001. We formalize this as adversarial modality interactions, extending the PID interaction taxonomy to decompose strategically generated unique information into truthful and adversarial subcomponents.

### Descriptions

#### `MidtermPaper.ipynb`
Contains all experimental work, including exploratory data analysis, statistical tests, model evaluation, and figure generation. 

#### `Multimodal_AI_Project_Midterm.pdf`
Written midterm report, whcih includes the problem statement, methodology, experiments, results, and conclusions. 

### `Figures/`
Stores all figures generated from `MidtermPaper.ipynb`. 

### `Data Pipeline/`
Contains scripts responsible for data scraping and preprocessing from all modalities.

Core scripts may include:
- `mmai_midterm_report.ipynb`: notebook for scraping Zillow (using HasData API), U.S. Census Bureau data, and Google Static Map and Street View images
- `clip_script.py.py`: aligns listing images with listing descriptions using CLIP
- `data_cleaning.py`: cleans data
- `data_collection.py`: python script for scraping new Zillow listings for tabular data and other modalities (census, GSV, satellite, images, listing descriptions, etc.)
- `data_maintenance.py`: python script for filling missing data (Census, GSV, Satellite) of existing listings in dataset, downloading listing photos from Zillow URLs, and scraping property listing descriptions and price history
